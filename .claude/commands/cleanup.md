---
description: 分類／標記收件匣，整理雜訊
---

請幫我整理收件匣的分類與標籤。

步驟：
1. 用 `list_labels` 取得現有使用者標籤與其 ID。
2. 用 `search_threads` 掃描收件匣，依主題／寄件者歸納可分類的信件。
3. **先列出建議的分類動作清單給我看**（哪些信 → 加什麼標籤 / 標重要 / 建議封存），等我確認。
4. 我確認後，再用 `label_thread` 等工具執行。

規則：
- 不要把任何信移到垃圾桶或刪除，除非我明確指定。
- 需要的新標籤可以用 `create_label` 建立，但建立前先告訴我。
- 批次操作一律先給清單、後執行。
